# ThinkHub icon concepts

Three original geometric TH monograms, authored as SVG paths without a font dependency.
The revised B monogram was selected as the default ThinkHub icon. Its production SVG is
`gui/assets/io.github.thinkhub.ThinkHub.svg`, with PNG launcher sizes in `gui/assets/icons/`.
The installer installs these under the app ID `io.github.thinkhub.ThinkHub` for all new installs.

- A — TrackPoint: graphite tile, white TH and a red pointing-stick accent in the H.
- B — Separate: distinct T and H letters with a small red dot above the H.
- C — Red badge: a solid red tile and white TH for stronger color at launcher size.

All icons use a 128-unit viewBox with transparent space around the rounded tile. The comparison
board shows a large preview and actual 64, 32 and 24 pixel versions. SVG sources remain the
masters; PNG files are rendered previews.
